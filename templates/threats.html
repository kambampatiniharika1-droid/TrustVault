THREATS.md — System Threat Modeling & Mitigation Report

1. Broken Object Level Authorization (BOLA / IDOR)

Threat: An attacker alters document IDs in URL parameters (/download/doc_payroll_2026) to exfiltrate other departments' files.

Mitigation: authorize_read() enforces live SQLite ACL lookups on every request before streaming bytes. Client-side hiding is never relied upon.

Status: Closed and verified in automated tests.

2. Overprivileged Administrator Bypass

Threat: Administrators use platform privileges to access ungranted employee files.

Mitigation: Zero-trust separation. Admin can view document metadata, but file download endpoints return 403 Forbidden without an explicit grant.

Status: Closed.

3. Audit Log Tampering & Repudiation

Threat: An attacker modifies or deletes database logs to cover up illicit downloads.

Mitigation: Every audit entry stores SHA-256(previous_hash + payload). Modifying any historical log breaks the chain.

Status: Cryptographically chained structure enforced.
